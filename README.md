## Publicar en GitHub Pages (repositorio `lab02-red-estudiantes`)

```powershell
cd D:\com.gaol.unad\laboratorio_02\sitio_estudiantes
git init -b main
git add -A
git commit -m "Lab02 versión estudiante"
git remote add origin https://github.com/guillermootalora/lab02-red-estudiantes.git
git push -u origin main
```

Después vaya a **Settings → Pages → main / (root) → Save**. La página queda en `https://guillermootalora.github.io/lab02-red-estudiantes/`.

## Insertar en Google Sites

En Google Sites, vaya a **Insertar → Insertar → Por URL**, pegue la dirección de arriba y elija **Página completa**.
